# FIAT · Pax et Bonum

Local React + TypeScript + Vite prototype for the Catholic FIAT hackathon organised by the Archdiocese of Singapore.

Run `npm install`, then `npm run dev` to open the prototype at http://127.0.0.1:5173/. `npm run build` checks TypeScript and creates dist. `npm run preview` serves the production build locally at http://127.0.0.1:4173/.

The prototype includes the pixel stained-glass welcome page and a local reflection interaction. It uses local state; no credentials, cloud services, or backend are needed.

Folders: src holds application code, internal holds design decisions and project notes, and runtime holds ignored local artifacts. Read AGENTS.md and internal/design-language.md before changing the UI.

No official event date, registration flow, or sign-in is configured. Development and demos run locally.
